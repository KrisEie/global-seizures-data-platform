# Source spreadsheets

Download the required Individual Drug Seizure workbooks from https://dmp.unodc.org/downloadIDS and place your local `.xlsx` copies in this directory. They are ignored by Git and not redistributed here. The original coursework used the 2011–2017, 2018–2023 and 2024 workbooks available in 2024–2025; newer releases may need column mapping changes.
